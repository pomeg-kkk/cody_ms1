# 개발 워크스테이션 구축

## 1. 프로젝트 소개
Linux, Docker, Git/GitHub를 활용하여
개발 환경을 구축하는 프로젝트입니다.

## 2. 개발 환경
- OS: Windows
- Linux: WSL Ubuntu
- Shell: Bash
- Docker: 버전 확인 후 작성
- Git: 버전 확인 후 작성

- [x] Linux 기본 명령어 실습
- [x] 파일 및 디렉토리 권한 변경

- [x] hello-world 실행
- [x] Ubuntu 컨테이너 실행
